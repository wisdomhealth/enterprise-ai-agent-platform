# 正式准备门清单

10 周目标排期仅在以下准备门全部提供证据并由责任角色确认后开始。当前基线不包含任何客户凭证或生产资产，因此所有 gate 明确处于 **未就绪** 状态。

| Gate | Owner | Evidence | State |
|---|---|---|---|
| 客户确认首版范围、角色和验收负责人 | 客户产品负责人 | 待提供：已批准范围、角色表与验收负责人记录 | 未就绪 |
| Google Cloud 项目、Drive/Gmail API 和专用连接身份可用 | 客户 Google Cloud 管理员 | 待提供：项目、API 启用与连接身份验证记录 | 未就绪 |
| 获准知识目录、代表性 PDF/Word 和脱敏邮件样本可用 | 客户数据负责人 | 待提供：授权目录与脱敏样本清单 | 未就绪 |
| Claude API 账户及数据使用配置确认 | 客户 AI 平台负责人 | 待提供：账户可用性与数据使用配置确认记录 | 未就绪 |
| 回归集与保留验收集的构建责任人、初始样本和标注规则确认 | 客户验收负责人 | 待提供：责任人、初始样本与标注规则 | 未就绪 |

准备门未通过时只允许低风险设计验证，不开始承诺的 10 周交付时钟。
